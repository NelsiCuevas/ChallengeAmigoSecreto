# Proyecto: Juego Amigo Secreto

Este proyecto corresponde a una aplicación web elaborada con **HTMl, CSS y JavaScript**, en ella puedes:

- Agregar nombres de amigos a una lista.
- Visualizar los nombres de los amigos agregados.
- Sortear un amigo de manera aleaoria sin que se repita.

##Funcionalidades:

1. **Agregar amigos**
  - El usuario debe ingresar un nombre en el campo y agregarlo con el botón añadir.
  - Los nombres se van actualizando automáticamente en la pantalla.

2. **Sortear amigo**
  - Al hacer clic en el boton sortear amigo, se selecciona aleatoriamente un nombre.
  - Los nombres sorteados no se repiten.
  - Se genera una mensaje cuándo todos los amigos sean sorteados.
